# Проверки кода

В каталоге 27 тестов в восьми файлах. Используется стандартный `unittest`.
Тесты работают на небольших искусственных данных и временных файлах;
исходные Parquet задания для них не нужны.

## Как запустить

Используйте `.venv`, созданную по [основной инструкции](../README.md), с зависимостями
из `requirements/notebook.txt`. Откройте терминал в корне репозитория.
Активировать окружение не нужно: команды обращаются к его Python напрямую.

**Windows / PowerShell:**

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

**Linux / macOS:**

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Ожидаемый итог: `Ran 27 tests` и `OK`.
Для отдельной группы добавьте `-p test_submission.py` перед `-v` в команду своей ОС.

Установка по основной инструкции уже подключает пакеты из `src/`.
Повторная установка зависимостей и ручная настройка `PYTHONPATH` не требуются.

## Что проверяется

| Файл | Тестов | Проверяемое поведение |
| --- | ---: | --- |
| [test_core.py](test_core.py) | 7 | Нормализация запросов, группировка, знаменатель Recall и повторы, порядок при равных оценках, RRF, стемминг. Оценки BM25 сравниваются с ручным расчётом; пустой запрос и неизвестные слова дают нулевые оценки. |
| [test_ranking.py](test_ranking.py) | 6 | Строгая группировка учитывает перестановки и окончания. Ранее просмотренные группы остаются в dev. Не найденные поиском positives входят в знаменатель Recall; отбор обучения сохраняет найденные positives. Дополнительно проверяются обратные ранги и запрет оценки исходного holdout без фиксации эксперимента. |
| [test_history.py](test_history.py) | 2 | История использует только обучающие группы, исключает собственную группу запроса и возвращает кандидатов только из текущего корпуса. Неизвестные слова не создают совпадения. |
| [test_geo.py](test_geo.py) | 2 | Расстояние корректно считается через 180-й меридиан. Географический канал требует близости и текстового совпадения; без центра локации возвращает пустую выдачу. |
| [test_selection.py](test_selection.py) | 1 | Объединение выдач сохраняет первые 40 результатов новой модели, пропускает повторы и заполняет оставшиеся места. Проверяется и случай отсутствия кандидатов старой модели. |
| [test_submission.py](test_submission.py) | 4 | Корректный и пустой ответ принимаются. Отклоняются пропуски и повторы запросов, неверный регистр ID, лишняя колонка, больше 50 объявлений, повторы, неизвестные ID и неверные разделители. |
| [test_freeze.py](test_freeze.py) | 3 | Форматирование JSON не меняет его отпечаток, изменение значения меняет. Бинарные артефакты сравниваются побайтово. |
| [test_layout.py](test_layout.py) | 2 | Пути считаются от файла настроек. Изменение исходного модуля меняет отпечаток исходного эксперимента даже при прежних параметрах модели. |
| **Всего** | **27** | |

В нескольких тестах есть `subTest`: это дополнительные случаи внутри одного
тестового метода, они не увеличивают итоговое число 27.

## Что проверяется отдельно

Эти тесты не обучают CatBoost, не пересчитывают выдачу для всех 2 452 запросов и
не подтверждают Recall на скрытой разметке Авито. Проверка отдельных функций
также не заменяет аудит разделения реальных данных.

Для пересчёта текущего ответа запустите
[notebooks/check.ipynb](../notebooks/check.ipynb). Он выполняет тесты, подготавливает
данные, восстанавливает готовую модель, заново строит benchmark-индексы и признаки,
сохраняет новый CSV и сравнивает его с корневым `answer.csv` побайтово.
Успешный итог содержит `status: passed` и `answer_identical: true` в
`work/quality/check_report.json`.

Проверка в чистом окружении и условия воспроизведения описаны в
[docs/reproduction.md](../docs/reproduction.md). Пересчёт с готовой моделью не
повторяет её обучение. Для запуска обучения служит
[notebooks/solution.ipynb](../notebooks/solution.ipynb) с `rebuild = True`.

Фактическая локальная оценка находится в
[fresh_metrics.json](../results/improved/fresh_metrics.json), а проверка разбиения
и обучающих пар в [leakage_audit.json](../results/improved/leakage_audit.json).
Навигация по проверяемым модулям: [src/README.md](../src/README.md).
