# Исходные данные

Для полного запуска положите сюда три файла из задания:

- `train.parquet` — 497 673 пары «запрос — выбранное объявление»;
- `benchmark_queries.parquet` — 2 452 запроса для ответа;
- `benchmark_items.parquet` — каталог из 189 212 объявлений.

Архив данных указан в условии задания:
[Яндекс Диск](https://disk.yandex.ru/d/sNhfo0YOjGtufg).
Данные не включены в Git и не скачиваются программой автоматически.

Если они уже лежат в другой папке, укажите её в `data_dir` файла `ranking.toml`.
Для просмотра сохранённых результатов исходные таблицы не нужны.
