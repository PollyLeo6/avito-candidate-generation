# Результаты

Все методы оценены на одних запросах и полном корпусе из 515 895 объявлений.

| Метод | Dev Recall@50 | Holdout Recall@50 |
| --- | ---: | ---: |
| BM25 + RRF | 28.96% | 27.76% |
| RRF с локацией | 61.27% | 58.70% |
| CatBoost | 74.10% | 72.45% |

Прирост CatBoost на holdout: **44.69 п.п.** Парный bootstrap, 95% интервал: 42.37–46.89 п.п.

Для ответа выбран `catboost_pairlogit` по dev; у CatBoost оставлено 50 деревьев.
Обучение: 7042 запросов с найденными positives, 848,569 пар. Запросы без найденных positives пропускаются только при обучении; в оценке они остаются.

Это локальная оценка по наблюдаемым положительным парам. Результат на закрытом тесте Авито неизвестен.

В wall-time этапа обучения попал длительный перерыв между продолжениями сессии. Эти секунды нельзя считать замером скорости обучения; внутренний журнал CatBoost показывает 21 мин 11 с.

## Где остаются потери

- dev: Recall расширенного пула 88.08%, после CatBoost — 74.10%; полных промахов пула — 230.
- holdout: Recall расширенного пула 86.34%, после CatBoost — 72.45%; полных промахов пула — 268.

## Примеры dev

Первые примеры по фиксированному порядку запросов; это не ручные правила поиска.

**Появились попадания:** «бурение скважины под воду свыше 150 метров»; «аренда буханки»; «очистка участка от деревьев пестречинский район»; «репетитор по английскому языку сельмаш»; «услуги юриста долги».

**Потерялись попадания:** «чертежи компас-3d»; «аренда зала для практик»; «байер грузия»; «дробление веток»; «ассенизатор дмитров».

**Не найдены даже в пуле:** «аренда микроавтобуса 22»; «культивировать участок»; «маникюр красноярск советский пайон»; «копка колец»; «обучение тантрическому массажу».

## Проверки

- Группы train/dev/holdout не пересекаются; ранее просмотренные группы исключены из нового holdout.
- Код, данные обучения, настройки и модель зафиксированы до holdout.
- Recall независимо пересчитан по строковым ID.
- В CSV ровно 2 452 запроса и 50 уникальных объявлений на каждый; все ID принадлежат benchmark.
- Полные логи и версии библиотек сохранены рядом.

После открытия holdout параметры не менялись. Повторение этого эксперимента не является новым независимым тестом.

Полный расчёт, включая построение индексов и обучение с нуля, повторён в изолированном окружении. Метрики совпали, `answer.csv` совпал побайтово. [Условия проверки](reproduction.md).
