# Проверка воспроизводимости

Модель с 38 признаками проверена в отдельной копии репозитория и новом окружении Python 3.12.10.
Зависимости установлены по `requirements/notebook.txt`; `pip check` прошёл успешно.
Перед запуском рабочие индексы и признаки отсутствовали.

Через Jupyter выполнены все 6 кодовых ячеек `check.ipynb`:
27 тестов, подготовка истории, построение индексов, признаки и предсказания
для 2 452 запросов по 189 212 объявлениям. Тогда CSV с переводами строк LF совпал побайтово.
Время без установки зависимостей: 501.32 с.

`solution.ipynb` выполнен через Jupyter в режиме `rebuild = False`,
все 13 кодовых ячеек завершились успешно.

Повтор полного обучения текущей версии в этом чистом окружении не выполнялся.
Обучение и подбор проведены отдельными этапами; исходные индексы взяты из ранее
проверенного расчёта. Дополнительно проверено точное совпадение всех 38 признаков
на 20 запросах каждой из трёх выборок: train, dev и dev с расширением по расстоянию.

Исходные отчёты: [reproduction_before_crlf.json](../results/improved/reproduction_before_crlf.json),

## Совпадение с отправленным файлом

Файл `reply_2589047_4.txt` содержит те же 2 452 строки и тот же порядок объявлений,
но использует переводы строк CRLF. В сохранение CSV добавлен явный параметр
`line_terminator="\r\n"`, одинаковый для Windows, Linux и macOS.
Модель, признаки, выбор кандидатов и все предсказания остались прежними.

Предсказание повторно рассчитано сохранённой моделью по ранее проверенным
признакам. Полученный `answer.csv` побайтово совпал с отправленным файлом.
Повторно прошли 27 тестов. Чистый запуск всего поиска после смены переводов
строк отдельно не повторялся; предыдущая полная проверка сохранена выше.

Текущие отчёты: [submitted_file_check.json](../results/improved/submitted_file_check.json),
[reproduction_check.json](../results/improved/reproduction_check.json).

CSV сравнивается с приложенным побайтово, без нормализации переводов строк.
