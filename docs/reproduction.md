кандидаты и признаки построены заново. CatBoost заново обучен на 700 деревьев,
после чего выбор по dev снова оставил 50 деревьев.

Полный пересчёт выполнен на коде коммита `d0783ca70d7b8b6a51edf7f47245d4f6caf80ece`. В итоговом репозитории
дополнительно исправлено сравнение JSON-отчётов: оно не зависит от отступов,
порядка ключей и окончаний строк Windows/Linux. Эта правка отдельно проверена
на переформатированной копии всех защищённых отчётов; изменение параметров
по-прежнему отклоняется. Код поиска, признаков, обучения и выбора модели не менялся.
Исходный снимок до этой правки сохранён в `results/frozen_experiment_original.json`.

## Условия запуска

Windows, CPU, Python 3.12.10, отдельное окружение без системных Python-пакетов.
Вычислительные версии зафиксированы в `requirements/lock.txt`, версии Jupyter
и его зависимостей - в `requirements/notebook.txt`. Выполнен `pip check`.
Полный расчёт занял 43.5 мин в этом запуске. Время на другой машине может отличаться.

Все 18 кодовых ячеек notebook последовательно выполнены с `rebuild = True`
обычным Python в изолированном окружении. Для этого запуска интерфейс Jupyter
не использовался. Отдельно в том же окружении через Jupyter выполнены все
18 ячеек с `rebuild = False`; это проверка интерфейса и сохранённых результатов.

Проверялись те же данные и настройки, без нового подбора по holdout.
Повтор не является новой независимой оценкой качества.
Другие ОС и архитектуры процессора этим запуском не проверены.

Подробный машинный отчёт: [full_reproduction.json](../results/full_reproduction.json).

В ноутбуке также прошли 20 тестов. Это проверка inference без повторного обучения.

Отчёт: [quick_check.json](../results/quick_check.json).

## Проверка после переноса файлов по папкам

Ноутбуки перенесены в `notebooks/`, настройки в `configs/`, Python-модули в `src/`,
списки зависимостей в `requirements/`. Изменены только пути, установка пакета
и учёт новых путей в контрольных суммах. Поиск, признаки, обучение и модель не менялись.
Предыдущий снимок контрольных сумм сохранён без изменений в
`results/frozen_experiment_before_layout.json`; текущий снимок содержит описание переноса.

В отдельной копии репозитория создано новое окружение Python 3.12.10.
Установка по `requirements/notebook.txt` и `pip check` прошли успешно.
Оба ноутбука запускались через Jupyter из папки `notebooks/`:

- `check.ipynb`: все 7 кодовых ячеек, 22 теста и пересчёт всего benchmark с пустой папкой `work/`.
  `train.parquet` при этой проверке отсутствовал. Ответ совпал побайтово;
  время без установки зависимостей - 304,34 с, около 5 минут.
- Подготовка полного эксперимента: корпус и разбиение пересозданы из исходных данных,
  отчёт о разбиении и контрольные суммы совпали.
- `solution.ipynb`: все 18 кодовых ячеек в режиме просмотра сохранённых результатов,
  с `rebuild = False`. Проверка зафиксированного эксперимента пройдена.

Полное обучение после переноса повторно не запускалось. Его отдельная проверка
описана выше; код обучения и параметры остались теми же.
