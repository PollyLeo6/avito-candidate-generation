# Настройки запуска

Оба основных ноутбука используют [improved.toml](improved.toml).
Для обычной проверки результата менять его не требуется.

## Пути

| Поле | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `data_dir` | `../data` | Три исходных Parquet из задания |
| `work_dir` | `../work` | Создаваемые индексы, история, признаки и рабочие предсказания |
| `results_dir` | `../results/improved` | Сохранённая итоговая модель, параметры, отчёты и логи |

Относительные пути отсчитываются от расположения TOML, то есть от `configs/`.
Можно указать абсолютный путь к данным. Например, путь `../data` означает
папку `data/` в корне репозитория при любой рабочей папке ноутбука.

## Выборки и параметры

- `train_queries = 8000` и `dev_queries = 2000` задают размеры выборок для
  подготовки обучения и выбора модели. После поиска кандидатов обучение
  использует 7 385 запросов, для которых найден хотя бы один положительный пример.
- `holdout_queries = 2000` относится к первоначальной проверочной выборке.
  Итоговый holdout из 1 000 других запросов резервируется отдельно в
  [protocol.py](../src/avito_improved/protocol.py). Его группы не пересекаются
  с предыдущей оценкой и обучением.
- `threads = 2` используется общими этапами построения индексов. Итоговые модули
  также ограничивают вычисления двумя потоками.
- `seed = 20260920` сохранён в настройках эксперимента. Это не единственный seed
  проекта: правила разбиения находятся в [common.py](../src/avito_retrieval/common.py)
  и [prepare.py](../src/avito_ranker/prepare.py), а фиксированные seed обучения
  и выборки отрицательных примеров заданы в модулях итогового решения.

Параметры поиска и обучения не все вынесены в TOML. Пределы поисковых выдач
заданы в [retrieval.py](../src/avito_improved/retrieval.py) и
[candidates.py](../src/avito_ranker/candidates.py), радиус поиска в
[geo.py](../src/avito_improved/geo.py), параметры CatBoost в
[model.py](../src/avito_improved/model.py).
Выбранное число деревьев и способ объединения выдач записаны в
[selected.json](../results/improved/selected.json).

Для воспроизведения приложенного ответа используются опубликованные значения.
Изменение выборок, признаков или параметров создаёт другой эксперимент;
проверка сохранённой модели в таком случае может остановиться на несовпадении снимка.

## Остальные конфиги

| Файл | Для чего сохранён |
| --- | --- |
| [ranking.toml](ranking.toml) | Обучение и оценка исходной модели из `avito_ranker` |
| [ranking.example.toml](ranking.example.toml) | Пример настроек исходного решения |
| [check.toml](check.toml) | Рабочие пути прежней проверки исходной модели |

`check.toml` не выбирается по имени ноутбука: текущий `check.ipynb` явно читает
`improved.toml`. Последовательность этапов приведена в [карте пайплайна](../docs/pipeline.md).
