# Окружение

Для проверки через ноутбуки достаточно установить [notebook.txt](notebook.txt)
в отдельное окружение Python 3.12.10. Он подключает [lock.txt](lock.txt), поэтому
отдельно ставить каждый список не нужно. Команды для Windows, Linux и macOS
приведены в [основном README](../README.md).

| Файл | Для чего нужен |
| --- | --- |
| [notebook.txt](notebook.txt) | Окружение для обоих ноутбуков: библиотеки решения, JupyterLab и ядро Python |
| [lock.txt](lock.txt) | Зафиксированные версии библиотек вычислительной части и её зависимостей |
| [base.txt](base.txt) | Основные библиотеки для запуска модулей; без полного окружения Jupyter |
| [experiments.txt](experiments.txt) | Дополнительные библиотеки отдельного символьного эксперимента |

Строка `-e .` устанавливает локальные пакеты из `src/`, поэтому команду `pip install`
нужно запускать из корня репозитория. Дочерние процессы этапов используют тот же
Python, что и ядро ноутбука. Выбор ядра **Avito ranking** после установки нужен,
чтобы Jupyter видел эти пакеты и именно зафиксированные зависимости.

GPU для решения не нужен. Расчёты выполняются локально; после установки
библиотек и размещения исходных данных обращения к внешним API не используются.
